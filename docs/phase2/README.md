# Phase 2 Client Package

Deliverables for explaining, scoping, and quoting the client's Phase 2 requests on top of the delivered nopCommerce 4.90 marketplace.

## How to use

1. Send **[05-phase2-modular-proposal.md](./05-phase2-modular-proposal.md)** as the main overview.
2. Attach **[02-quote-pyk-header-link.md](./02-quote-pyk-header-link.md)** for the Pyk button price (fill in your rate).
3. Attach **[01-mac-address-admin-security-note.md](./01-mac-address-admin-security-note.md)** when discussing MAC / admin security.
4. After reviewing the harajbozorg APK reference, send **[06-harajbozorg-apk-analysis.md](./06-harajbozorg-apk-analysis.md)** and **[07-revised-phase2-plan-after-apk-analysis.md](./07-revised-phase2-plan-after-apk-analysis.md)**.
5. Ask the client to complete:
   - **[03-questionnaire-vendor-backup-scope.md](./03-questionnaire-vendor-backup-scope.md)** before quoting Module E
   - **[04-questionnaire-duplicate-detection-scope.md](./04-questionnaire-duplicate-detection-scope.md)** before quoting Module C
