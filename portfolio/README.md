## ⚡ Quick Steps to Upload on Upwork

1. Open your Upwork profile and click **"Add a new portfolio project"**.
2. Open [`UPWORK_PROJECT_DETAILS.md`](./UPWORK_PROJECT_DETAILS.md) and copy:
   - **Project title**: `nopCommerce 4.90 Enterprise E-Commerce & AI Marketplace`
   - **Your role**: `Lead Software Architect & .NET Core E-Commerce Specialist (C#, nopCommerce, AI)`
   - **Project description**: Copy the verified 538-character summary.
   - **Skills and deliverables**: Select the recommended tags (`nopCommerce`, `C#`, `.NET Core`, `ASP.NET Core`, `Plugin Architecture`, `Artificial Intelligence`, `Visual Search`, `Multi-Vendor Marketplace`, `Payment & Wallet Systems`, `RESTful API Integration`).
3. Click the **Image icon** in the content section:
   - Set **`01_cover_thumbnail.png`** as your **Cover Image**.
   - Upload the presentation showcase graphics from [`images/`](./images/) and real application figures from [`images/real_app_figures_english/`](./images/real_app_figures_english/).
4. Click **Publish**!
