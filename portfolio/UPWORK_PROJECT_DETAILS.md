### 5. Project Technical Highlights

- **Core Framework:** .NET 9 / ASP.NET Core, C#, nopCommerce 4.90 (Clean Plugin Architecture)
- **Database Layer:** Microsoft SQL Server, FluentMigrator Schema Migrations, Entity Framework Core / Linq2Db
- **AI & ML Integration:** AvalAI API, Multimodal Visual Vector Matching, Voice Transcription & Embedding Cosine Search
- **Event Bus:** Asynchronous In-Memory Event Consumers (`IConsumer<OrderPlacedEvent>`)
- **Security:** SMS Two-Factor Authentication (2FA), Device Binding Tokens, IP Whitelisting
- **API Architecture:** Clean RESTful JSON Controllers with Non-Intrusive Bearer/Session Authentication
